# morhirc

Free Software Developer

Windows向けツールを中心に、個人でフリーソフトを制作・公開しています。

## Software

- **[morhirc PDF エディター](https://morhirc.github.io/pdf-editor/)** — 無料・登録不要。ブラウザ上でPDFに文字・画像・図形を追加・編集できる高機能ツール。
- **[NetNalyze](https://morhirc.github.io/netnalyze/)** — Network Diagnostic Analyzer for Windows
- **[Winすっきり](https://morhirc.github.io/winsukkiri/)** — Windows 11を、もっとシンプルに。
- **[Winの腹の中](https://morhirc.github.io/winnohara/)** — Windows PCの状態確認・トラブル切り分け支援ツール
- **[ChatAttic](https://morhirc.github.io/chatattic/)** — ChatGPTの会話を保存・検索・閲覧
- **[Maplimo](https://morhirc.github.io/maplimo/)** — Google Maps Timelineの記録をPCで振り返るビューア
- **[VolScreen](https://morhirc.github.io/volscreen/)** — Windowsの音量変更を画面上にOSD表示
- **[MouseEnter](https://morhirc.github.io/mouseenter/)** — マウス右ボタン長押しでEnterキーを入力
- **[AtoKana](https://morhirc.github.io/atokana/)** — 英数で入力してしまったローマ字を日本語変換へ
- **[OpenDaw-JP](https://morhirc.github.io/opendaw-jp/)** — openDAW を日本語で利用しやすくするための日本語対応版
- **[UVR-JP](https://morhirc.github.io/uvr-jp/)** — Ultimate Vocal Remover GUI を日本語で利用しやすくするための日本語対応版
